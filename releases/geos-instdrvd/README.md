# Area6510

### InstallDriveD
This is a small utility for GEOS 2.x with Configure/GeosConf64 2.3, which can be used to install and configure drive D: (1541/71/81 only).
The program has been rebuild from the binary release, since the original version contained a bug that caused it to destroy parts of the content stored in the GEOS-DACC memory. This could lead to a crash.

#### WARNING
With a configured drive D:, DeskTop V2 will not be able to swap disk drives. Use of this program is only recommended when an alternative desktop is used (e.g. dualTop or TopDesk).
